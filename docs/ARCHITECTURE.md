# Архитектура

## Общая схема

```text
Браузер
  │  HTML/JS
  ▼
FastAPI (app.py)
  ├─ ChatBot (chatbot.py)
  │    ├─ Reformulator (reformulator.py) ──► LLMClient (llm_client.py)
  │    └─ HybridSearcher (search_engine.py)
  │         ├─ FAISS (косинусное сходство)
  │         └─ BM25 + RRF
  ├─ DocumentGenerator (document_generator.py) ──► LLMClient
  └─ QueryLogger (query_logger.py) ──► SQLite

Scheduler (scheduler.py)
  └─ parser.py ──► parsed_texts/ ──► create_index.py ──► FAISS + BM25
```

## Поток обработки запроса

1. Пользователь описывает ситуацию в чате.
2. LLM переформулирует её в три юридических запроса.
3. HybridSearcher выполняет поиск по исходному и переформулированным запросам.
4. FAISS и BM25 формируют кандидатов; RRF объединяет ранжирования.
5. Документы дедуплицируются, для них строятся контекстные сниппеты.
6. LLM генерирует ответ по найденным фрагментам (RAG).
7. Ответ, задержки и результаты записываются в SQLite.

## Гибридный поиск

- **FAISS**: эмбеддинги `paraphrase-multilingual-MiniLM-L12-v2`, размерность 384,
  L2-нормализация, скалярное произведение = косинусное сходство.
- **BM25**: лексическое ранжирование по токенам.
- **RRF**: `score(d) = Σ 1 / (k + rank_r(d))`, `k = 60`.
- Результаты фильтруются по порогу, дедуплицируются по имени файла и
  ограничиваются топ-K.

## Индексация

- Нарезка через `RecursiveCharacterTextSplitter` с юридическими разделителями
  («УСТАНОВИЛ:», «РЕШИЛ:», «ОПРЕДЕЛИЛ:»).
- Размер чанка — 800 символов, перекрытие — 150.
- Для коллекций > 10 000 чанков используется IVF-индекс FAISS.
- Сохраняются `document_index.faiss`, `bm25_index.pkl`, `chunks_data.pkl`.

## Генерация документов

- Типы: исковое заявление, претензия, ходатайство, жалоба.
- Генерация опирается на найденные прецеденты и структурированные реквизиты.
- Проверяются обязательные поля, незаполненные места, номера дел и ссылки на
  нормы.
- Документ всегда содержит дисклеймер и требует проверки юристом.
- Экспорт в DOCX через `python-docx`.

## Основные модули

| Модуль | Ответственность |
| --- | --- |
| `app.py` | REST API, HTML-страницы, жизненный цикл приложения |
| `chatbot.py` | Сессии, сценарий search/clarify, логирование |
| `search_engine.py` | FAISS, BM25, RRF, сниппеты, перезагрузка индексов |
| `reformulator.py` | Промпты переформулировки, ответа и уточнения |
| `llm_client.py` | Ollama / OpenAI-совместимый API, повторы, очистка ответа |
| `document_generator.py` | Черновики документов, валидация, DOCX |
| `parser.py` | Selenium-парсер sudact.ru, реестр URL |
| `create_index.py` | Построение FAISS и BM25 |
| `query_logger.py` | SQLite-логи и обратная связь |
| `scheduler.py` | Периодический сбор и переиндексация |
| `config.py` | Переменные окружения и пути |
| `utils.py` | Токенизация, RRF, сниппеты, извлечение норм |
